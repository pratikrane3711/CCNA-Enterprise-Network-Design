# CCNA-Enterprise-Network-Design
Enterprise Network Design using Cisco Packet Tracer with VLAN, OSPF, HSRP, DHCP and Inter-VLAN Routing.
Project Overview
This project demonstrates the design and implementation of a secure enterprise network using Cisco Packet Tracer. The network connects Mumbai and Delhi branches through an ISP and includes routing, switching, VLAN segmentation, redundancy, security, and network services.
